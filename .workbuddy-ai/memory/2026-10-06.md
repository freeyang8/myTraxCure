## 蓝框（锁定选区）判定链路 —— 复查结论

### 触发条件（GazeDetector，core/gaze_logic/gaze_detector.py）
`update(point, block_key, block_height_px)` 是唯一入口，先 append 进 deque(maxlen=60)，
再按 `point.timestamp - dwell_seconds` 裁剪（保留 1 帧越界锚点，否则跨度永远 < dwell）。
按 `block_key is None` 分两条路：

- **段落模式** `_update_paragraph`：stable = dwell>=0.6s **且** dominant 众数占比>=0.5 **且** offset<=max(40, 段高)。
  带换段磁滞 `min_dominant_frames=3`（新 key 需在窗口末尾连续命中 3 帧才取代 dominant）。
  只看质心 offset，**不看 variance**。
- **点模式** `_update_point`：stable = variance<=60 **且** offset<=40 **且** 窗口跨度>=0.6s。

关键参数来自 GazeConfig：dwell_seconds=0.6 / dominant_ratio=0.5 / min_dominant_frames=3 /
hit_tolerance_px=100 / tolerance_ratio_of_block_h=0.7 / max_variance_px=60 / max_offset_px=40。

### 命中 → 蓝框（main_window.on_gaze_point, ~L546）
1. overlay 显示中 → return（冻结）；被遮挡 → return（注意：**无头姿门控**，当前只有 fallback_manager 那条）
2. `hit_test(tol=hit_tolerance_px=100)` 精确命中；未命中再做「最近块回退」，
   回退容差 `min(100, 块高*0.7)`
3. `paragraph_union_bbox(block)` 聚合该 para_key+page 的所有块，取并集 bbox（文档坐标）
   → `document_to_screen` 转屏幕（全局）坐标
4. `detector.update(...)` 判稳定
5. 未稳定：hover_key 变化则清蓝框 + 清 last_hover_key，return
6. 稳定（mode=="paragraph" 且 screen_region 非空）：
   - 转 viewer 本地坐标（减 mapToGlobal 原点）
   - `locker.lock_block(local, bounds=(0,0,w,h), max_size=...)`
     * `max_size`：逐句模式传 (viewer.w, viewer.h)，否则 None（用 RegionConfig 1000x400）
     * 超限（w>max_w 或 h>max_h）→ 返回 None = "整页一大块" → **回退点模式**
   - 否则点模式：`locker.lock(local_point, bounds)` → 400x120 居中矩形
7. `feedback.show_region(region)` + `self.detector.reset()`（0.8s 只触发一次）

### 两种模式（重要，代码已比早期版本新）
- **逐句步进**（ReadingConfig.step_mode 默认 **True**）：StepRenderer，
  一屏 44px 大字只放能完整显示的 N 句；**无全局滚动，scroll_offset 恒 0**，
  句子级 block 每屏重注册（可见句写屏内坐标，其余句 y=-1e5 避免最近块回退误命中）。
  句子 text = `sentence-{i}`，para_key 同名 → 一句即一段，蓝框=整句。
- **连续滚动**：DocumentRenderer 整篇纵向版面 + 像素滚动，蓝框=段落并集。

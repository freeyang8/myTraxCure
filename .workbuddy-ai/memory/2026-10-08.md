# 2026-10-08

## 为"如何读懂本项目"梳理全景
- 用户诉求：怎么读懂 myTraxCure（毕设项目）。已通读全部 core/ui 源码，产出阅读路线。
- 项目定位：基于 eyetrax 的眼动驱动翻译桌面软件。PyQt6 + eyetrax 0.4.0 + mediapipe + Ollama(hy-mt1.5-1.8b-fixed@11434)。
- 入口：main.py → mytraxcure/app.py:run()（Qt 前先跑 ensure_calibration 三态决策）→ MainWindow。
- 主链路（眼动）：CameraThread.frame_ready → _on_gaze_frame(extract→blink/头姿门控→predict→smoother→DPI换算) → on_gaze_point
  → mapper.hit_test(容差)→段落并集bbox→detector.update(驻留0.6s)→locker.lock_block/lock→feedback 蓝框
  → 空格 on_space→_trigger_translation→CacheStore.get/TranslationWorker→Ollama→overlay 浮层。
- 鼠标模式：_poll_cursor QTimer(33ms) 取 QCursor.pos() 复用同一 on_gaze_point。
- 两大阅读模式（关键分叉）：逐句步进 StepRenderer(默认,句子即单位,无全局滚动,scroll=0) ↔ 连续滚动 DocumentRenderer(段落即单位)。
- 命中选路：段落并集框，超限(None)回退 400x120 点框。
- 分层：core（config/types/gaze/gaze_logic/file/translation/fallback，无 Qt 依赖或轻 Qt）+ ui（PyQt6 视图）。
- 校准：data/calibration/default_0_{1920x1080,2560x1600}.pkl；CalibrationStore 按 user_camera_WxH 命名。
- 翻译缓存：sqlite data/cache.db，键=文本+语言+backend+model+page+block 的 sha256；预翻译与即时翻译共用 make_segment_key。
- 交付：show_widget 架构/数据流图 + 分层阅读路线文字指南。
